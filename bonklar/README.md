# BonKlar

Kostenloser, mobiler Prototyp für Kassenbons, Ausgaben und Preisvergleiche.

## Funktionen
- Kassenbon per Kamera/Fotoupload
- kostenlose OCR im Browser mit Tesseract.js
- Laden, Datum, Summe und Produktzeilen prüfen/korrigieren
- Monatsbudget und Ausgabenübersicht
- Produktvergleich nach Händler und Grundpreis
- Preisverlauf, Durchschnitt, günstigster bisheriger Preis
- lokale Speicherung im Browser
- JSON Export/Import
- als PWA installierbar

Die App liegt im Unterordner `/bonklar/` der GitHub-Pages-Seite.
