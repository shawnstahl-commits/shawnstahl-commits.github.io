MANIC EMU · AUTO-SYNC

iPhone-Saves aus Manic EMU übernehmen

Manic EMU unterstützt iCloud-Sync und Save-Export. ROMDex ist jetzt auf diesen Emulator vorbereitet und kann neue Save-Versionen später automatisch vergleichen.

Manic EMU erkannt
1 · Manic EMU ✓Emulator erkannt und als Quelle vorgemerkt.
2 · Save-ZugriffMit Manic-Mitgliedschaft: Dateien → iCloud Drive → Manic EMU. Ohne Mitgliedschaft: Auf meinem iPhone → Manic EMU → Datas.
3 · Auto-AnalyseNeuen Save erkennen → Pokémon, Dex, Shinys und Entwicklungen automatisch vergleichen.
📱 Manic-EMU-Verbindung
iCloud: Dateien → iCloud Drive → Manic EMU
Lokal: Dateien → Auf meinem iPhone → Manic EMU → Datas
Die Web-Version kann auf dem iPhone den Ordner aus Sicherheitsgründen noch nicht dauerhaft im Hintergrund beobachten. Für nahezu automatischen Sync bauen wir später die Kurzbefehle-/Cloud-Verbindung dazu.

⚙️ iPhone-Kurzbefehl verbinden

Für jedes Testgerät wird ein eigener geheimer Schlüssel verwendet. Dafür ist kein Login nötig.

Kein Login nötig. Erzeuge hier einmalig den Schlüssel.
Kurzbefehl: Save-Datei aus Manic auswählen → „Inhalt von URL abrufen“ → Methode POST → Header X-ROMDEX-TOKEN = dein Schlüssel → Header X-ROMDEX-FILENAME = Dateiname → Request-Body = Save-Datei.
Automation: Kurzbefehle → Automation → App → Manic EMU → „Wird geschlossen“ → diesen Kurzbefehl ausführen → „Sofort ausführen“.
Noch keine automatischen Saves geprüft.
